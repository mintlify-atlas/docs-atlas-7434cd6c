## Quick Start

<Steps>
  <Step title="Open Polytrack">
    Go to [kodub.itch.io/polytrack](https://kodub.itch.io/polytrack) and launch the game in your browser.
  </Step>
  <Step title="Pick a map">
    Choose any map from the [Maps](/maps/amethyst-skyscraper) section and copy its import code.
  </Step>
  <Step title="Import the track">
    In Polytrack, open the **Track Editor**, select **Import**, paste the code, and confirm. See the full [How to Import](/how-to-import) guide for details.
  </Step>
  <Step title="Race!">
    Load the imported track and start driving.
  </Step>
</Steps>

<Tip>
  If a track runs slowly on your device, check whether a **Lite** version is available — Amethyst Skyscraper has one that removes decorative scenery for a significant performance boost.
</Tip>
