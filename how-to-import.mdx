Polytrack's Track Editor has a built-in Import feature that accepts encoded map strings directly — no file uploads, no external tools, and no account required. Just copy the import code from a map's page in this collection, paste it into the editor, and the track loads instantly. The steps below walk you through the entire process.

## Importing a Map

<Steps>
  <Step title="Open Polytrack">
    Go to [kodub.itch.io/polytrack](https://kodub.itch.io/polytrack) and launch the game in your browser. No account or download is needed — the game runs entirely in the browser.
  </Step>
  <Step title="Copy the Import Code">
    Navigate to the map's page in this docs site and locate the code block containing the import string. Click the copy button (or select all and copy manually). The string is very long — make sure you copy it in its entirety, from the very first character to the very last.
  </Step>
  <Step title="Open the Track Editor">
    From the Polytrack main menu, select **Track Editor** to enter the editor interface.
  </Step>
  <Step title="Click Import and Paste">
    Inside the Track Editor, find the **Import** button, typically located at the top of the editor UI. Click it to open the import dialog, paste the full code string into the text field, and confirm. Polytrack will decode the string and reconstruct the track.
  </Step>
  <Step title="Drive the Track">
    The map loads immediately once the import is confirmed. Select the track and start a run — no further setup required.
  </Step>
</Steps>

<Warning>
  Do not truncate or partially copy the import code. The string must be copied in full — even a single missing character will cause the import to fail or the track to load incorrectly.
</Warning>

<Tip>
  If a track runs slowly or drops frames, check whether a Lite version is available. Amethyst Skyscraper, for example, has a dedicated Lite variant with all decorative scenery removed, which runs significantly better on lower-end hardware.
</Tip>

<Note>
  Import codes are version-specific snapshots of a track at the time of publishing. If TiniTheBagel releases an updated version of a map, the code on the relevant map page in this docs site will be updated to reflect the latest publish. Always copy from the map page to ensure you have the most current version.
</Note>

## Choosing Between Versions

Some maps in this collection are available in multiple variants:

- **Full versions** include all scenery, decorative objects, and visual details as TiniTheBagel originally designed them. These look the best but may require more processing power.
- **Lite versions** strip out decorative objects and non-essential scenery elements to improve frame rate and overall performance without changing the track layout itself. Amethyst Skyscraper has a Lite variant.
- **Repolished versions** are updated remakes of older tracks that incorporate design improvements and refined details. Opal Palace has a Repolished version that supersedes the original with updated geometry and polish.

When in doubt, start with the full version. If you notice performance issues, switch to the Lite variant. If a Repolished version exists, it is generally the recommended experience over the original.
