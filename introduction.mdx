Polytrack is a browser-based low-poly racing game playable at [kodub.itch.io/polytrack](https://kodub.itch.io/polytrack). This site is a curated collection of custom maps built by TiniTheBagel, each distributed as a self-contained import code — a single encoded string that you paste directly into the game's Track Editor to load the full map instantly. No downloads, no installs, and no account required.

## What Is an Import Code?

An import code is a long encoded string that represents a complete Polytrack track layout — every road segment, checkpoint, scenery object, and finish line packed into a single line of text. The string typically begins with `v1n…` (newer format) or `PolyTrack…` (older format). To use one, copy the full string from a map's page, open the Polytrack Track Editor, paste it into the **Import** field, and confirm. The track loads immediately and is ready to race.

## Versions and WIP Snapshots

Several maps in this collection have gone through visible development stages. Amethyst Skyscraper and Bismuth Mines both have archived WIP (work-in-progress) directories containing older snapshots from earlier in their development. These are preserved for reference but are not the recommended way to play either track.

The import code published in each map's main file is always the latest, most complete version. When TiniTheBagel releases an update, that main file is replaced with the new code, so the map page in this docs site will always reflect the current recommended version.
